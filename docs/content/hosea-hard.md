## Design intent for this tier

Per Kachi: "hard... needs very deep scripture knowledge." This tier draws on verses that are
narratively significant but less likely to be immediately recognized — secondary details and exact
phrasing — and requires typed recall wherever the format allows. Difficulty skews to rank 5
throughout. It stays inside the same guardrails as every other tier: verbatim WEB text only,
narrative fact only, no doctrinal position required.

**This tier does not loosen any of medium's format restrictions** — it is recall-only by design at
every item, so the restricted verses (1:2, 1:10, 3:1, 3:5, 6:1-3) are format-compliant automatically,
but each is still individually confirmed below rather than assumed safe by construction.
