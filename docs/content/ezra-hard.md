## Design intent for this tier

Per Kachi: "hard... needs very deep scripture knowledge." This tier draws on verses that are
narratively significant but less likely to be immediately recognized — precise numbers, secondary
names, and exact phrasing — and requires typed recall (no multiple-choice scaffolding) wherever the
format allows. It stays inside the same guardrails as every other tier: verbatim WEB text only,
narrative fact only, no doctrinal position required.

## Pivotal Scenes — reused from `docs/content/ezra.md`, no new scenes added

Same 5 scenes as `medium` and `easy`: (1) Cyrus's Decree and the Return (Ezra 1); (2) Rebuilding the
Altar and the Temple Foundation (Ezra 3); (3) Opposition, the Work Resumes, and the Temple Completed
(Ezra 4-6); (4) Ezra the Scribe: Devotion to the Law (Ezra 7); (5) National Repentance Over
Intermarriage (Ezra 9-10). **Scene 5's exclusion-based bounding — resolved by Kachi Okere on
2026-08-25 — carries forward unchanged: Ezra 9:1-2, 10:3, 10:10-12, and 10:44 remain permanently
excluded from challenge-ready content at every tier.** No item below draws on any of those four
excluded verses.

## Contested Territory

Everything already flagged in `docs/content/ezra.md` applies unchanged, including the Scene 5
mass-divorce bounding resolved by Kachi Okere.

**Confirmed for this tier:**

- **Scene 5 (item 8)** stays strictly within the already-approved confession/repentance verses
  (9:6) and never touches the excluded divorce/expulsion clauses. No new bounding decision required.
- **Ezra 6:22, "the king of Assyria."** Checked: this is a plain textual/historical curiosity (by
  this point Assyria's former territory had long been absorbed into the Persian empire, so the text
  applies the older regional name to the Persian king), not a live cross-tradition doctrinal dispute
  — Bible Hub's aggregated commentators (Gill, Pulpit Commentary) all read it the same way, as a
  historical-naming note rather than a contested claim. **No structural rule needed**; the item
  grades only the word "Assyria" as printed in WEB, verbatim.
- **Ezra 1:1's prophecy-fulfillment structural rule** is not engaged this tier — 1:1 is not used in
  any item above.
- **Chronology of Ezra and Nehemiah.** Item 9 (boss sequence) sequences events only within this
  book's own internal narrative order — same bounding as `medium` and `easy`.
- **No new contested ground otherwise** — every other new verse (1:2, 1:9, 3:8, 6:3, 7:21, 7:27) is
  plain narrative description (a proclamation's wording, an inventory count, a name, a dimension, an
  administrative decree, a blessing) with no live cross-tradition disagreement found.
